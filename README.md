# Tilemap Space Defense


## 프로젝트 개요
- 장르: 모바일 세로형 타워디펜스
- 엔진: Unity 2022.3
- 화면 구성: 세로형 플레이 화면
- 개발 방향: 타일맵 기반 전투, 데이터 기반 타워 설계, 오브젝트 풀링 적용

## 필수 기능 구현
### 1. 전투 루프
- 전투 루프: 적 생성 및 이동, 영웅 공격, 적 체력 감소, 적 사망처리 : 완료


### 2. 웨이브 시스템
- 웨이브: 승리/실패 판정 (지휘관 체력 기반) : 완료

### 3. 영웅 시스템
- 영웅 시스템: 소환 및 승급 (재화소모 포함) : 완료

## 선택 기능 구현
### 1. 탐사정 시스템
- 넥서스와 미네랄을 왕복하는 탐사정 구현
- 미네랄 수집 시 자원 증가 처리
- 탐사정 추가 소환 기능 구현
- 탐사정 소환 비용 증가 및 최대 수량 제한 적용

### 2. 수리 시스템
- 잠긴 타일 선택 시 수리 UI 표시
- 미네랄을 사용해 타일 수리 가능
- 수리 완료 후 일반 배치 타일처럼 사용 가능

### 3. 현상금 시스템
- 적 처치 시 골드 보상 지급

## 추가 구현 내용
- 타워 교체 시스템
  - 같은 등급 내 랜덤 종류로 교체 가능
- 골드 / 미네랄 이중 재화 시스템
- 타이틀 / 로비 / 스테이지 씬 전환 구조
- 몬스터 / 투사체 / 적 체력바 오브젝트 풀링
- 소환 / 수리 / 승급 / 교체를 하나의 UI 구조로 재사용


## 영웅 시스템
- 영웅 종류: White / Red / Blue
- 영웅 등급: Normal / Rare / Epic
- 소환 방식: 확률 기반 랜덤 소환
- 승급 방식: 같은 종류, 같은 등급 영웅 2기 이상일 때 승급 가능
- 교체 방식: 같은 등급 내 랜덤 종류로 교체 가능

## 자원 시스템
### Gold
- 영웅 소환에 사용
- 적 처치 보상으로 획득

### Mineral
- 탐사정을 통해 수집
- 타일 수리 및 영웅 교체에 사용

## 기술 구현 포인트
- Tilemap 기반 배치형 전투 구조
- ScriptableObject 기반 타워 데이터 관리
- ObjectPoolManager를 활용한 몬스터 / 투사체 / 적 체력바 풀링
- SummonPopupUI 재사용 구조
- WaveSystem 중심의 웨이브 및 승패 관리
- ProbeManager를 통한 탐사정 생산 및 자원 흐름 관리

## 폴더 구조
- `Assets/Scripts/Common`
- `Assets/Scripts/Enemies`
- `Assets/Scripts/Towers`
- `Assets/Scripts/Player`
- `Assets/Scripts/UI`
- `Assets/Prefabs`
- `Assets/Scenes`

## 핵심 스크립트
- `WaveSystem`
  - 웨이브 진행 및 승패 판정 관리
- `EnemySpawner`
  - 적 생성, 처치 보상, 도착 시 피해 처리
- `TowerSpawner`
  - 영웅 소환 / 승급 / 교체 처리
- `SummonPopupUI`
  - 소환 / 승급 / 교체 / 수리 UI 처리
- `ProbeManager`
  - 탐사정 생성, 비용 증가, 최대 수량 관리
- `ProbeWorker`
  - 탐사정 이동 및 미네랄 수집 처리
- `ObjectPoolManager`
  - 몬스터 / 투사체 / 적 체력바 풀 관리

## 마무리
필수 기능을 중심으로 전투 루프와 웨이브 진행 구조를 우선 구현했고,  
선택 기능으로 탐사정, 수리, 현상금 시스템을 추가해 자원 흐름과 전략 요소를 확장했습니다.  
추가적으로 오브젝트 풀링과 재사용 가능한 UI 구조를 적용해 성능과 확장성을 함께 고려했습니다.
